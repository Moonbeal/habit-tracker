# 🌟 Щоденник звичок з AI Асистентом (Habit Tracker)

Сучасний веб-застосунок для відстеження та формування корисних звичок з **персональним AI асистентом** та красивим фіолетово-лавандовим дизайном.

## ✨ Особливості

### 🤖 AI Асистент (НОВЕ!)
- 💬 **Чат-асистент** - спілкуйтесь з AI про ваші звички та мотивацію
- 🎯 **Персональні рекомендації** - AI аналізує ваші звички та пропонує нові
- 📊 **AI інсайти** - розумний аналіз вашої статистики та прогресу
- 🔮 **Прогнози та поради** - AI допомагає передбачити проблеми
- ✍️ **Генерація мотивації** - персоналізовані мотиваційні повідомлення

### 📋 Основні функції
- 📝 **Створення звичок** - додавайте нові звички з описом, категорією та кольором
- ✅ **Відстеження виконання** - відмічайте виконання звичок кожного дня
- 🗓️ **Календар** - переглядайте історію виконань у зручному календарі
- 🔥 **Серії днів (Streaks)** - відстежуйте поточну та найкращу серію виконань
- 📊 **Статистика** - детальна статистика з графіками та діаграмами
- 🏆 **Досягнення** - розблоковуйте досягнення за прогрес
- 🎨 **Красивий UI** - сучасний дизайн з плавними анімаціями
- 📱 **Адаптивна верстка** - працює на всіх пристроях
- 💾 **LocalStorage** - дані зберігаються локально у браузері

## 🛠️ Технології

## 🚀 Швидкий старт

### Встановлення

1. Клонуйте репозиторій або завантажте файли проєкту

2. Встановіть залежності:
```bash
npm install
```

3. Запустіть сервер розробки:
```bash
npm run dev
```

4. Відкрийте браузер за адресою: `http://localhost:5173`

5. **(Опціонально)** Налаштуйте AI Асистента:
   - Перейдіть на вкладку "AI Асистент"
   - Отримайте безкоштовний API ключ на [Google AI Studio](https://aistudio.google.com/app/apikey)
   - Вставте ключ у застосунок
   - Детальна інструкція: [AI_SETUP.md](AI_SETUP.md)

## 🎯 Функціонал

### Звички
- Створення звичок з назвою, описом, категорією та кольором
- 6 категорій: Здоров'я, Спорт, Навчання, Робота, Особисте, Інше
- Вибір кольору акценту для кожної звички
- Відмітка виконання за поточний день
- Видалення звичок

### Календар
- Перегляд історії виконань по місяцях
- Навігація між місяцями
- Візуальне відображення виконаних/невиконаних днів
- Виділення поточного дня

### Статистика
- Загальна кількість звичок
- Загальна кількість виконань
- Найкраща серія днів
- Графік виконань за останні 7 днів
- Діаграма розподілу по категоріях
- Топ-5 звичок за серіями

### Досягнення
- 🎯 Перша звичка
- ⭐ Колекціонер звичок (5 звичок)
- 🔥 Тиждень стабільності (7 днів підряд)
- 🌟 Місяць дисципліни (30 днів підряд)
- 🏅 Ідеальний тиждень
- 💪 Сотня виконань (100 разів)
- 🎨 Майстер звичок (10 звичок)

## 🌐 Розгортання на Vercel

1. Створіть акаунт на [Vercel](https://vercel.com)

2. Встановіть Vercel CLI:
```bash
npm install -g vercel
```

3. Зберіть проєкт:
```bash
npm run build
```

4. Розгорніть на Vercel:
```bash
vercel
```

Або використайте веб-інтерфейс Vercel:
1. Завантажте проєкт на GitHub
2. Підключіть репозиторій до Vercel
3. Vercel автоматично визначить налаштування Vite
4. Натисніть "Deploy"

## 💡 Поради по використанню

1. **Почніть з малого** - додайте 2-3 звички, які хочете сформувати
2. **Будьте послідовні** - відмічайте виконання кожного дня
3. **Відстежуйте прогрес** - регулярно переглядайте статистику
4. **Святкуйте успіхи** - розблоковуйте досягнення
5. **Не здавайтесь** - якщо пропустили день, продовжуйте далі

## 🎨 Кастомізація

### Зміна кольорової схеми

Відредагуйте файл `tailwind.config.js`:

```javascript
theme: {
  extend: {
    colors: {
      purple: {
        // Ваші кольори
      },
    },
  },
}
```

### Додавання нових категорій

Відредагуйте тип `Habit` у файлі `src/types/Habit.ts`:

```typescript
category: 'health' | 'sport' | 'study' | 'work' | 'personal' | 'other' | 'your-category';
```
